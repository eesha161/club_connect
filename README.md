# ClubConnect 🚀

An app I built to help students manage clubs, track volunteer hours, and connect with each other.

## What is this?

ClubConnect is a cross-platform mobile app (works on iOS and Android!) that makes school life easier. It replaces messy paper sign-in sheets and confusing spreadsheets with a clean, easy-to-use app.

**Key Features:**
- 🔎 **Find Clubs**: Browse and join clubs that match your interests.
- 📅 **Events**: RSVP to events and add them to your Google Calendar.
- 📷 **QR Check-in**: Scan a QR code to check in to events (no more paper!).
- 🏆 **Earn Badges**: Get verified volunteer hours and earn badges for your profile.
- 💬 **Chat**: Connect with other members in the club Q&A.

👉 **[Check out my full Design & Features Guide](DESIGN_AND_FEATURES.md)** to see all 12 extra features I added and why I designed it this way.

## Getting Started

If you want to run my code, here's what you need:

1. **Flutter SDK** (make sure it's installed).
2. **Firebase Account** (since I didn't include my private keys, you'll need your own `google-services.json` and `GoogleService-Info.plist`).

### How to run it

1. **Clone the repo**
   ```bash
   git clone <repo-url>
   ```

2. **Get dependencies**
   ```bash
   flutter pub get
   ```

3. **Run it!**
   ```bash
   flutter run
   ```

## Why I made this

I wanted to solve the problem of losing track of volunteer hours. Plus, I wanted to learn Flutter and building a real app with a backend seemed like a great challenge.
